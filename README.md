# Campus Event Management System

## 📌 Project Description
This project is a web application that helps students discover and manage campus events efficiently.

## 🚀 Features
- User login
- View events dashboard
- Filter events (Tech, Cultural, Sports, Academic)
- Real-time data from PostgreSQL

## 🛠️ Tech Stack
- Frontend: React
- Backend: Node.js, Express
- Database: PostgreSQL

## ▶️ How to Run (Local Setup)

### 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/campus-event-management-system.git

### 2. Backend setup
cd backend
npm install
node server.js

### 3. Frontend setup
cd frontend
npm install
npm start

### 4. Database setup
- Install PostgreSQL
- Create database: campus_events
- Run SQL script (provided in docs or below)
